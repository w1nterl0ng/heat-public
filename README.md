# Heat — Digital Edition

A digital adaptation of **Heat: Pedal to the Metal** for Mac, Windows, and browser.

---

## Downloads

Visit the **[Releases page](https://github.com/w1nterl0ng/heat-public/releases)** to download the latest build.

| Platform | Notes |
|----------|-------|
| macOS | Universal `.app` — unzip and run |
| Windows | `.exe` + data folder — unzip and run |
| WebGL | Browser playable — no install needed |

The [releases/latest.json](releases/latest.json) manifest is machine-readable and always points to the most recent stable build.

---

## Track Editor

Create and export custom tracks at **[https://w1nterl0ng.github.io/heat-track-editor/](https://w1nterl0ng.github.io/heat-track-editor/)**.

Exported `.zip` track packages can be dropped into the game's `TracksImport` folder (`Application.persistentDataPath/TracksImport`) and the game will import them automatically on next launch.
