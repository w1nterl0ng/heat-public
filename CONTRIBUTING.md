# Contributing a community track

This is a manually curated, non-commercial track library. A submission is not automatically published.

## Package requirements

- Export a `track_{id}_v2_package.zip` from the Track Editor.
- Include `manifest.json`, `track_{id}_v2.json`, and `preview_{id}.jpg`.
- Include a unique lowercase `trackId`, package version, creator credit, and valid checksum.
- Test import in the current beta before submission.

## Content policy

Submit only original work or material you have permission to distribute. Do not submit official board scans, copied official board art, or other content that infringes rights. Credit every creator whose work appears in the package.

You retain ownership of your original work. By submitting, you permit this repository to host and link the package for the community library. Maintainers may correct credit, unpublish, or remove a package when needed for quality, compatibility, or rights concerns.

## Review and publishing

Open the track-submission issue form and attach the ZIP. A maintainer reviews metadata, import behavior, creator credit, preview, and rights/content statement. Approved packages are uploaded as GitHub Release assets; the catalog generator then writes the public listing.

For removal or rights concerns, see [rights.html](rights.html).
